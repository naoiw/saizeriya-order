# SAIZERIYA ORDER

サイゼリヤの料理写真と商品名から4桁の注文番号を当てる、非公式の個人向けクイズアプリです。

現段階では **データセット管理・公式商品写真のローカル収集処理・React画面の土台** までを整備しています。ゲームモードとギャラリーは別Issueです。

## 開発環境

- Node.js 20.19+ または 22.12+
- npm

```bash
npm install
npm run collect:menu -- --limit 5
npm run dev
```

最初は5件で画像収集の動作を確認してください。問題なければ、対象の人気メニューをすべて収集できます。

```bash
npm run collect:menu
npm run test:collector
npm run build
```

- `--dry-run`: 商品情報と画像URLの検出のみ（保存なし）
- `--limit N`: 先頭N件だけ確認
- `--force`: 取得済み画像も再ダウンロード

画像の収集先は `public/images/<4桁番号>.<拡張子>`、商品情報は `src/data/menu.json` です。
初期状態では、公式ページ上で確認できた4件のメタデータだけを格納しています。画像ファイルは未同梱です。

## データについて

- ソース: [サイゼリヤ公式 人気メニュー](https://www.saizeriya.co.jp/menu-popular/)
- メニューブック全商品ではなく、**人気メニュー一覧から商品詳細ページと番号付きの写真URLを確認できる商品だけ**を対象にします。
- 画像のURLと商品番号の対応は、ファイル名が `<商品番号>_` または `<商品番号>-` で始まる場合のみ採用。見つからない場合は推測せずスキップします。
- 商品名・番号・写真は変更される場合があります。正しいグランドメニューに合っているか利用前に目視確認してください。
- 「すぐに／あとで」など複数番号の商品や、公式人気メニュー以外の商品は別途データ拡充が必要です。

詳細は [docs/data-management.md](docs/data-management.md) を参照してください。
