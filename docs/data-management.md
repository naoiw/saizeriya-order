# 商品データと画像の管理

## データソースと管理方針

注文番号・商品名・任意の公式商品画像URL・出典は `src/data/menu.json` の配列で管理します。**注文番号単位のレコード**であり、ギャラリーの1カード単位ではありません。

現在の内容（2026年11月時点）は、**114注文番号、すべて有効、ギャラリー93カード、画像未設定80件**です。現行の人気メニューページなどを元にした部分的なデータであり、最新のグランドメニュー全件の収録や、店舗での注文可否を保証しません。

- レコードをGitで管理するため、番号の修正はレビュー可能です。
- 画像がある場合は公式サイトの`https://www.saizeriya.co.jp/files/…`をブラウザから直接参照し、リポジトリには保存しません。
- 公式ページからの情報収集は**補助的な処理**です。商品と写真の正しさは人間が確認します。
- 出典が変わった・画像が廃止された・商品が終了した場合も、未確認の変更を自動で反映しません。

## レコードのスキーマ

`src/lib/menu.ts` で読み込み時に形式検証し、`scripts/check-dataset.mjs` でコマンドラインから検証します。

| フィールド | 必須 | 用途 |
| --- | --- | --- |
| `code` | 必須 | 重複のない4桁の**文字列**（先頭ゼロを保持） |
| `name` | 必須 | クイズと一覧に表示する商品名 |
| `imageSource` | 任意 | 公式のHTTPS画像URL。未確認時は省略し、画面には「画像なし」を表示 |
| `pageUrl` | 任意 | 公式商品詳細ページ、または朝サイゼの公式ページ |
| `sourceUrl` | 任意 | 番号を確認した参照資料（2026年2月版ユーメニュー） |
| `menuScope` | 任意 | `regular`（通常・省略可）、`morning`（朝限定）、`seasonal`（季節） |
| `verification` | 任意 | `reference` は過去資料による候補・現時点の販売は要確認 |
| `groupId` | 任意 | 同じ商品としてギャラリーでまとめるグループID |
| `variantLabel` | 任意 | 「すぐに」「あとで」「赤」「白」など注文番号ごとの違い |
| `enabled` | 任意 | `false` のときクイズ・ガチャ・ギャラリーから除外。省略時は有効 |

グループを作る場合は、同じ商品に属する全レコードへ**同じ`groupId`と各番号の`variantLabel`**を指定します。グループ内の名前・画像URL（未設定でも可）・公式ページ／参照資料URL・販売区分・表示有効状態は共通にします。各レコードには `pageUrl` または `sourceUrl` が必要です。

### バリエーションの例

ティラミス クラシコは、提供タイミングで2つの番号に分かれます。`imageSource` は両レコードで同じ公式画像を指定します。

```json
[
  {
    "code": "3201",
    "name": "ティラミス クラシコ",
    "imageSource": "https://www.saizeriya.co.jp/files/3201_%E3%83%86%E3%82%A3%E3%83%A9%E3%83%9F%E3%82%B9%E3%82%AF%E3%83%A9%E3%82%B7%E3%82%B3.webp",
    "pageUrl": "https://www.saizeriya.co.jp/menu-popular/3201/",
    "groupId": "3201",
    "variantLabel": "すぐに"
  },
  {
    "code": "3901",
    "name": "ティラミス クラシコ",
    "imageSource": "https://www.saizeriya.co.jp/files/3201_%E3%83%86%E3%82%A3%E3%83%A9%E3%83%9F%E3%82%B9%E3%82%AF%E3%83%A9%E3%82%B7%E3%82%B3.webp",
    "pageUrl": "https://www.saizeriya.co.jp/menu-popular/3201/",
    "groupId": "3201",
    "variantLabel": "あとで"
  }
]
```

登録済みのグループ：

| 商品 | 共通グループ | 注文番号とラベル |
| --- | --- | --- |
| ティラミス クラシコ | 3201 | 3201「すぐに」、3901「あとで」 |
| イタリアンプリン | 3206 | 3206「すぐに」、3906「あとで」 |
| グラスワイン（120ml） | 3401 | 3401「赤」、3402「白」 |

グラスワインの共通公式ページは `/menu-popular/3401_0402/` です。このように`pageUrl`末尾と`code`が一致しない既知の例外は、`src/lib/menu.ts` と `scripts/check-dataset.mjs` の対応表で検証しています。**番号を追加・変更した場合は両者を更新**してください。

## 画像なし・未登録メニューの追加

- **5101セットドリンクバー**：誤画像URLを削除し、画像なしで有効化しました。5102（キッズ）・5103（単品）と1カードに表示します。
- **通常メニュー追加70番号**：2026年2月の[番号付き資料](https://www.umenu.jp/menus/18.html)に基づき `verification: "reference"` を設定。現行メニューとは区別します。
- **朝サイゼ8番号**：[公式ページ](https://www.saizeriya.co.jp/asasaize/)を出典とし、`menuScope: "morning"` を付与。
- **季節メニュー1302**：`menuScope: "seasonal"` と `verification: "reference"` を付与。
- **画像なし80番号**：`imageSource` を省略し、クイズは商品名で回答、ギャラリーは「画像なし」を表示します。
- **ガチャもクイズと同じ有効114番号から抽選**します。参考資料、朝、季節商品も抽選されますが、結果に販売状況・時間帯の注意書きを出します。実際の注文可否は店舗で確認してください。

有効件数とギャラリーのカード数は異なります。クイズとガチャは**注文番号ごと**、ギャラリーは**`groupId`ごと**に表示します。

## メニューの取得・更新

`scripts/collect-menu.mjs` が、公式の[人気メニュー一覧](https://www.saizeriya.co.jp/menu-popular/)から4桁の商品ページを探し、ページのタイトルと画像URLを解析します。逐次アクセスで待機時間を入れており、第三者の画像ファイルはダウンロードしません。

```bash
# まず画面出力だけ確認（menu.jsonは更新しない）
pnpm collect:menu --dry-run
# 取得するページ数を制限して試す
pnpm collect:menu --limit 5 --dry-run
# 内容を確認したうえでデータに新規レコードを追加
pnpm collect:menu
# ローカル検証
pnpm check:dataset
pnpm test:dataset
```

- **既存の手動検証済みレコードは上書きしません。** 既存商品が更新された場合は出典と写真を比較し、手動で修正します。
- 新規商品ページでタイトルや画像を確認できない場合はスキップします。すべて失敗した場合はエラーとして書き込みません。
- 公式の`og:image`等でメイン画像を優先し、`_rank`・`_comb`・`_block` の図版を誤って商品写真に採用しないよう処理します。
- **ファイル名に商品番号が入らないメイン写真もあります。** アロスティチーニ（1402）とパルマ風スパゲッティ（2304）はその例です。
- 正常に読み込めないURLや新しいメニュー番号を**推測で補完しない**でください。
- 公式サイトにアクセスするため、必要なときだけ実行し、頻繁な収集を避けてください。

## 検証の範囲

`pnpm check:dataset` は4桁の番号、重複、画像URLが存在する場合の公式ドメイン、`pageUrl`・`sourceUrl`、グループの整合性を検証します。画像がないこと自体はエラーではありません。`pnpm test:dataset` は現在のバリエーションと画像の取り扱いに関する回帰テストです。

**どちらもネットワークへアクセスして画像が表示されるかを確認する処理ではありません。** 写真と商品名の一致は開発プレビューで目視確認してください。ブラウザから公式サーバーへのアクセスが拒否された場合は代替表示になります。
