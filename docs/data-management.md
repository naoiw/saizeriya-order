# 商品データと公式画像URL

## スキーマ

`src/data/menu.json` は次の形式の配列です。

```json
[
  {
    "code": "2101",
    "name": "ミラノ風ドリア",
    "imageSource": "https://www.saizeriya.co.jp/files/2101_....webp",
    "pageUrl": "https://www.saizeriya.co.jp/menu-popular/2101/"
  }
]
```

| フィールド | 用途 |
| --- | --- |
| `code` | 4桁の文字列。商品ごとに一意 |
| `name` | 問題・一覧で表示する商品名 |
| `imageSource` | 公式商品写真の絶対URL。ブラウザの画像要素から直接参照 |
| `pageUrl` | 出典となる公式商品詳細ページ |

旧 `image`（`/images/2101.webp` のようなローカル画像パス）は廃止しました。
画像ファイルをデータセットと一緒にGit管理する必要はありません。

## 更新

```bash
pnpm collect:menu --dry-run
pnpm collect:menu
pnpm check:dataset
```

`collect:menu` は人気メニュー一覧から4桁の商品詳細ページを列挙し、各ページのタイトル・商品番号と一致する画像URLを抽出します。公式ドメイン、写真ファイル名の番号一致を確認してから保存します。アクセスは逐次実行し、間隔を空けます。公式サイトが変更された場合は推測で補完せず、エラーを出して既存データを維持します。

既存レコードは、対象ページを取得できなかった場合も自動削除しません。販売終了品や番号変更の有無は都度確認してください。グランドメニュー全件を網羅するものではありません。

`pnpm check:dataset` はJSONのデータ形式・重複・URLと番号の対応を確認します。ネットワークを使用しないため、画像のHTTP応答や実際の料理写真との一致までは保証しません。アプリ起動時の画像プレビューで実際の表示を確認してください。

## 画像配信の注意

画像は閲覧者のブラウザから直接 `www.saizeriya.co.jp` にリクエストされます。外部サイトからの画像読み込みを公式サイトが制限した場合、代替表示になります。直接参照は権利上の許可を意味しません。

以前のバージョンでダウンロードした `public/images/` の画像は不要です。既存ファイルはGit管理から引き続き除外されるため、削除しても構いません。

## 複数の注文番号を持つ商品

同じ商品でもクイズでは番号ごとに独立した1問です。ギャラリーでは `groupId` が等しいレコードを1枚のカードにまとめ、各番号に `variantLabel` のラベルを付けます。

例：

```json
[
  { "code": "3201", "name": "ティラミス クラシコ", "groupId": "3201", "variantLabel": "すぐに", "imageSource": "https://www.saizeriya.co.jp/files/3201_ティラミスクラシコ.webp", "pageUrl": "https://www.saizeriya.co.jp/menu-popular/3201/" },
  { "code": "3901", "name": "ティラミス クラシコ", "groupId": "3201", "variantLabel": "あとで", "imageSource": "https://www.saizeriya.co.jp/files/3201_ティラミスクラシコ.webp", "pageUrl": "https://www.saizeriya.co.jp/menu-popular/3201/" }
]
```

* `groupId`: 同じ商品としてまとめる識別子。2レコードとも共通に指定する。
* `variantLabel`: クイズ問題文にも出す選択条件（例: 「すぐに」「あとで」「赤」「白」）。
* `enabled: false`: 写真未確定などでクイズ・ギャラリーに表示しない保留用。データ自体は残す。

現在は3201/3901、3206/3906、3401/3402がグループです。ワインの商品詳細ページは `3401_0402/` ですが、注文番号は3401/3402です。

**公式メイン画像のファイル名に番号が含まれない場合があります。** 1402/2304や3401/3402は公式商品ページのメイン写真を使用しています。番号一致の画像ファイルを無条件に採用するとランキング図版を選ぶため、収集時は`og:image`を優先し、ランキング・組み合わせの図版は除外します。

収集スクリプトは手作業で検証済みの既存レコード（グループ・ラベル・画像・非表示設定を含む）を上書きしません。公式の仕様変更時はレビューしてから手動で更新してください。

セットドリンクバー5101は画像確認待ちのため`enabled: false`のまま管理します。実装再開後、正しい画像を見つけてから有効化してください。
