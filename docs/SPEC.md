# 機能仕様

## 概要

`SAIZERIYA ORDER` は、サイゼリヤの注文番号を覚えたりランダムな注文を楽しんだりする非公式のReact製シングルページアプリです。画面上部で **クイズ → ガチャ → ギャラリー** を切り替えます。

メニューの元データは `src/data/menu.json` です。**114注文番号／114件がクイズ対象／ギャラリー93カード／画像なし80件**（2026年11月時点）。件数はJSONの更新により変わります。非表示レコード（`enabled: false`）は、各モードの対象から外れます。

## クイズ

- 1回**5問**。有効な注文番号からランダムに選び、同じ4桁番号は1回に重複しません。
- 画像がない場合は写真エリアに「画像なし」を表示します。商品名・必要な場合は提供タイミングやワインの色を表示し、**4桁の番号**を入力します。
- 画面キーパッドと物理キーボード（数字、Backspace、Delete／Escape、Enter）で操作できます。数字4桁が揃うと回答可能です。
- 回答後は正解／不正解と正しい番号を表示し、次の問題へ進みます。終了後は正解数、正答率、各問の回答を表示します。
- 画像表示に失敗したときは、代替表示と「この問題をスキップ」を利用できます。
- 有効な注文番号が5件未満なら開始できません。

### 提供タイミングとワイン

同一商品でも注文番号が違う場合はクイズで独立した問題です。

## ガチャ

- 初期表示は**未抽選**。ボタンを押して初めて**5枠**の結果が出ます。
- **クイズと同じ有効114番号**から**復元抽出（重複あり）**で1枠ずつ独立に選びます。過去資料の70番号・朝サイゼ8番号・季節商品1番号も抽選対象です。80番号は画像なしですが、正常に抽選できます。同一番号や同一商品が何度も出る場合があります。
- 結果の各枠に商品写真（未設定なら「画像なし」）、商品名、番号、該当する場合はタイミング／色・販売状況の注意書きを表示します。「もう一度ガチャを回す」で再抽選できます。
- ブラウザでは `crypto.getRandomValues` を優先します。固定日時シードを使わず、毎回新しい乱数を取得します。
- 直前に出した**5枠すべてが同じ順序**で続く場合は再抽選し、それでも一致する場合は別の有効番号があれば1枠を差し替えます。**各枠の重複は禁止しません。**
- 直前の番号配列のみを同じタブの `sessionStorage` に保存し、更新後も完全一致する結果を避けます。ストレージが使用できない場合は保存せず抽選できます。
- ガチャ画面をF5で更新してもURLハッシュでモードは維持されますが、**結果は空に戻り、次のボタン押下まで抽選しません**。

## ギャラリー

- 有効メニューをカード／リスト表示し、商品名・4桁番号・ラベル（例:「あとで」「白」）で検索できます。全角数字入力にも対応します。
- 注文番号の昇順／降順、商品名の昇順／降順で並べ替えられます。
- `groupId` が同じレコードを1カードにまとめます。2件以上の番号をそれぞれラベル付きで表示します。画像なしでもカードを表示します。
- 公式商品詳細ページまたは2026年2月の番号資料への外部リンク、画像取得失敗時の代替表示を備えます。

## 画面・レスポンシブ動作

- URLハッシュ: `#quiz` / `#gacha` / `#gallery`。未指定・未知の値はクイズ表示。
- PC・スマートフォンに対応。クイズ進行中は幅620px以下で写真・キーパッド等を小さくし、画面が短い場合だけフッターを非表示にします。
- **スクロールは禁止しません。** 端末の高さ、表示倍率、画像エラーなどでコンテンツがあふれる場合は通常どおり縦スクロール可能です。
- ライトモードを維持し、操作ボタンには緑のアクセントを使用します。ヘッダー・フッターの共通レイアウトは他のnaoiw Pagesアプリと合わせています。

## 制限と保留事項

- 実店舗の最新メニューや価格、注文可能状況の完全性は保証しません。番号の確認は利用者側で行ってください。
- **セットドリンクバー（5101）** は誤画像URLを外し、画像なしの状態でクイズ・ガチャ・ギャラリーに表示します。
- 商品画像は公式URLをブラウザが直接読み込みます。取得制限・URL変更による表示失敗の可能性があります。
- 商品データと収集方法の詳細は [data-management.md](data-management.md)、未確認のメニューは [Issue #11](https://github.com/naoiw/saizeriya-order/issues/11) を参照してください。


## 追加データの出典と注意

- 追加70番号：2026年2月20日版の[ユーメニュー](https://www.umenu.jp/menus/18.html)。商品名と番号の参考資料で、現在の販売継続は未確認（`verification: "reference"`）。
- 朝サイゼ8番号：[公式朝サイゼ](https://www.saizeriya.co.jp/asasaize/)で確認。販売店舗・時間帯に制限（`menuScope: "morning"`）。
- 季節商品1302：[公式商品ページ](https://www.saizeriya.co.jp/menu-popular/1302/)参照。現在の販売期間は未確認（`menuScope: "seasonal"`）。
- 注文番号を確認できない地域・店舗・季節限定の商品は4桁クイズには登録していません。

画像がない商品でもスキップ必須とはせず、商品名から回答できます。**ガチャも114番号から抽選**し、現行の提供状況が未確認・店舗限定・季節限定の場合は結果ごとに注意書きを表示します。実際に注文する場合は店舗の最新メニューを確認してください。
